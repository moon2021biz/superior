必須

アカウント削除機能がない

Appleの審査ガイドライン5.1.1(v)：アカウント作成できるアプリは、アプリ内から本当に削除できる機能が必須。 今はsignOut（ログアウト）のみ。TestFlightの外部テスト審査は緩いため通っているが、本番の通常審査はほぼ確実にここで差し戻される。 設定→アカウントに「アカウントを削除」を追加し、Clerkユーザー削除＋Convex側データ削除＋確認ダイアログを実装する必要がある。

CODE
推奨

iPad対応をオフにする

app.jsonのios.supportsTabletがtrueだが、実際はiPad向けレイアウト最適化をしていない。 trueのままだとAppleがiPadのスクリーンショット提出・iPadでの見え方審査を求めてくる。 今回はiPhone専用としてfalseにするのが早い。1行の変更で即対応可能。

CODE
推奨

Clerkが本番用の鍵になっていない

EXPO_PUBLIC_CLERK_PUBLISHABLE_KEYがpk_test_...のまま。テスト用インスタンスは送信数・ユーザー数に制限があり、一般公開後の実運用には向かない。 MOONさんがClerkダッシュボードで本番インスタンスを作成→発行された鍵を教えてもらえれば、eas.jsonとapp.jsonの差し替えは私が対応する。
